# thatproject-greet

Use the following subcommand of `thatproject` to manage a thatproject project. E.g. if the subcommand is `init` then run `thatproject init`

## `greet`

**Usage:** `greet [OPTIONS]`

###### **Options:**

* `-n`, `--name <NAME>`

  Default value: `world`
